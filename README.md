## The line

> My doctor said I need more iron, so I started dating magnets. Finally, a relationship where I'm the one who gets attached.

An original one-liner (122 characters): a doctor's "more iron" prescription takes an unexpected turn into dating magnets, and the punchline lands on the double meaning of "attached".

## How to run

Requires Node 22.18 or later (runs TypeScript directly, no install needed):

```sh
node main.ts
```

This deterministically writes the line to `/output/entry.txt` (creating `/output` if needed). No network calls, no model calls at runtime — the line is a fixed string in `main.ts`. Running it twice produces byte-identical output.
